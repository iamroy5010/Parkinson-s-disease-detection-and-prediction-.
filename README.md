# Parkinson’s Disease Detection (Machine Learning)

## Project Overview
This project focuses on detecting Parkinson’s disease using machine learning techniques. The goal is to analyze biomedical voice data and identify patterns that help in early prediction of the disease.

##  What I Did
- Worked with a real-world dataset related to Parkinson’s disease  
- Cleaned and prepared the data for analysis  
- Performed feature selection to improve model performance  
- Applied machine learning models like SVM, Random Forest, and KNN  
- Compared model accuracy to find the best performing algorithm  

##  Tools & Technologies
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib  

##  Key Learnings
- Data preprocessing and cleaning  
- Feature engineering basics  
- Model training and evaluation  
- Understanding how ML can be used in healthcare problems  

##  Files in this Project
- `parkinson_disease.csv` – dataset used  
- `train_model.py` – model training script  
- `app_parkinson_top30_real_samples.py` – prediction script  
- `.ipynb` file – experimentation and analysis  

##  Conclusion
This project helped me understand how machine learning models can be applied to real-world problems like disease detection and how data plays a key role in prediction accuracy.
